Релаизация игры Motezuma's Revenge
==================================

Экран
-----

Размер тайла 8x8. Разрешение экрана 320x200, верхяя часть - статус (8 строк тайлов).

Комнаты
-------

Комнтаты в пирамиде нумеруются: первая цифра - номер этажа сверху, вторая - номер столбца.
::
                   (1, 1)
            (2, 1) (2, 2) (2, 3)
      (3,1) (3, 2) (3, 3) (3, 4) (3, 5)
                    и т.д.

Команты делаются в модуле rooms:
::

   void room_1_1(int **map)

Глобальные константы в rooms.h:
SCREEN_COLS - число столбцов на экране
SCREEN_ROWS - число строк на экране

Коды тайлов - через enum.

Процедурная генерация уровня
----------------------------

Чтобы не рисовать уровень по клеточкам, удобно сделать модуль генерации (generator.c).
::

   void map_fill_tiles(int **map, int width, int height, int x, int y, int fill_width, int fill_height, int tile);

Функция map_fill_tiles заполняет область в карте map с размерами width, height одним и тем же тайлом tile.
Координаты левого верхнего угла области x, y, ширина области fill_width, высота области fill_height.


Реализация библиотеки для разработки игр в жанре Платформер
===========================================================

Модуль backend
--------------

* Управляет окном: создает, закрывает окно приложения.
* Обрабатывает события клавиатуры, закрытия окна через крестик.
* Загружает изображения
* Выводит изображения полностью и частично
* Обновляет окно - вывод графики из буфера
* Не сделано: масштабирование экрана
* Задание области отсечения, x, y - координаты левого верхнего угла области отсечения, width, height - размеры области отсечения
::

   void set_clip(int x, int y, int width, int height);
   

Постоянная частота кадров
-------------------------

Можно установить частоту обновления экрана (в кадрах в секунду):
::

   void set_fps(int fps);

Чтобы была постоянная частота кадров необходимо в is_quit сделать замер времени начала кадра.
В update_window перед выводом буфера замеряется время окончания кадра. Вычисляется сколько времени длился кадр. Далее перед выводом графики необходимо вставить соответствующую задержку в зависимости от времени кадра.

Вывод шрифта (модуль font.c)
----------------------------

Шрифт задается как матрица картинок одинаковой ширины (char_w) и высоты (char_h), расположенная в одном файле font_file. offset - смещение (ASCII код первого символа в шрифте).
Символы должны идти в том же порядке, что и в таблице ASCII. kern - расстояние между символами при выводе теста.
::

   font_t *make_font(char *font_file, int char_w, int char_h, char offset, int kern);

Текст выводится для шрифта font, str - строка текста, x, y - координаты левого верхнего угла области текста.
Расстояние между символами задано в шрифте.
::

   void show_text(font_t *font, char *str, int x, int y);


Модуль graphics
---------------

* Выводит сетку из тайлов.
* Выводит спрайты.
* Выводит анимацию спрайтов.
* Позволяет выводить спрайты по слоям (z координаты).
::

   void pause_animation(animation_t *anim);
   void resume_animation(animation_t *anim);

Модуль audio
------------

* Инициализация аудио (audio_init)
* Закрытие аудио (audio_close)
* Микширование каналов звука
::

   void audio_close();

Микширование каналов
--------------------

Каждый канал имеет свой буфер с аудио данными. При инициализации аудио все буферы каналов заолняются нулями. Аудио формат - целый со знаком, 16 бит (short). Микшер соединяет данные всех каналов.
   

Модуль synth
------------

Синтезатор, генерирует синусоиду по заданной ноте.

Модуль physics
--------------

* Учет объектов
* Движение объектов по скорости и ускорению

Модуль collision
----------------

* Проверка пересечения прямоугольников

Редактор модели столкновений
----------------------------

Пользователь может нарисовать каркас объекта, состоящий из прямоуольников для проверки столкновений.

Модуль states
-------------

* Автомат состояний игровых объектов

Модуль interactions
-------------------

Пользователь может задавать какие функции нужно выполнить при столкновении объектов заданных типов.

Навигация ИИ
------------

Для навигации удобно использовать навигационный граф (модуль nav_graph.c).
Узлы графа должны содержать координаты. Необходимы операции, чтобы можно было создать граф (задать вершины и связи), получить информацию о вершинах и связях.

Модуль engine
-------------

Главный модуль движка.

* Задается мир, состоящий из карт

Графический интерфейс пользователя
----------------------------------

Для текущего окна можно добавить элементы графического интерфейса. Пользователь может создавать свои элементы интерфейса.
::

   struct gui_element_t {
	sprite_t *sprite; // изображение элемента
	gui_elements_list_t *children; // список дочерних элементов
   }

   gui_element_t *create_gui_element(image_t *im, int x, int y, int z);

   void gui_add_child(gui_element_t *elem, gui_element_t *child);
